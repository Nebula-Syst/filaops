# Marca PrintFlow

PrintFlow es un fork modificado de [FilaOps](https://github.com/BLB3DPrinting/filaops)
(BLB3D Printing, BSL 1.1). Estos logos son de PrintFlow; los de FilaOps/BLB3D no se usan.

| Archivo | Uso |
| --- | --- |
| `printflow-entero.png` | Logo completo (símbolo + nombre + lema). Pantalla de login, splash de la app, documentos. |
| `printflow-entero-claro.png` | Igual, para fondos claros (texto oscuro). |
| `printflow-corto.png` | Horizontal: símbolo + "PrintFlow". Menú lateral, cabeceras, Ajustes. |
| `printflow-corto-claro.png` | Igual, para fondos claros. |
| `printflow-chico.png` | Solo el símbolo "P" (transparente). Menú contraído, avatares, marca de agua. |
| `favicon.ico` / `favicon.png` | Pestaña del navegador (16–64 px). |
| `apple-touch-icon.png` | Icono al añadir a la pantalla de inicio (180 px, fondo oscuro). |
| `app-icon-1024.png` | Icono de la app móvil (1024 px, fondo oscuro). |
| `printflow-original.png` | Imagen original de la que salen todos (fondo #070A10). |

Todos salen de `printflow-original.png` quitando el fondo oscuro por luminancia
(se conservan los degradados). Las versiones en uso por la web están en
`frontend/src/nebula/brand/` y `frontend/public/`.
